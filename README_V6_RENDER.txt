EXION V6 — pacote completo para Render

Este pacote inclui a interface atualizada e o modo EXION Voz em tempo real.

Na barra de mensagem, o botão 📞 fica ao lado do microfone 🎙️. Ao tocar nele, o EXION abre a tela de voz com a bola/orb flutuante e solicita acesso ao microfone.

Também inclui Gemini, memória, visão/imagens, internet, GitHub e terminal seguro.

CONFIGURAÇÃO DO SERVIDOR
- AI_PROVIDER=gemini
- GEMINI_API_KEY=sua_chave
- GEMINI_LIVE_ENABLED=true
- GEMINI_LIVE_MODEL=gemini-3.8-live
- GEMINI_LIVE_VOICE=Orus

IMPORTANTE
O site exion-ai.onrender.com precisa ser atualizado/reimplantado com este pacote. O endereço antigo pode continuar servindo a versão anterior até um novo deploy.
